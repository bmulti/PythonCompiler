[intro]
Python Compiler, PyInstaller ব্যবহার করে Python প্রোগ্রামকে Windows প্রোগ্রামে রূপান্তর করে, পরীক্ষা করে এবং প্রকাশ করে। এর কাজের ধাপ হলো:
Code Browser অথবা Gateway Apps (Python সোর্স কোড) > Temp Compile (বিল্ড ও পরীক্ষার ফাইল) > Outputs (পরীক্ষা, তারপর প্রকাশ) > Compile Apps (সম্পূর্ণ অ্যাপ, Start Menu এবং নতুন Gateway এন্ট্রি)।
Code Browser যেকোনো ফোল্ডার থেকে Python ফাইল কম্পাইল করে। Gateway Apps আপনার gateway ফাইলে (gateway.json) তালিকাভুক্ত অ্যাপগুলো কম্পাইল করে। দুই তালিকাতেই ডান ক্লিক করে কোড দেখা যায়। Outputs তৈরি হওয়া ফলাফল পরীক্ষা করে এবং প্রকাশ করে। Log-এ সব ঘটনা সংরক্ষিত হয়। উইন্ডোর নিচের লাইনটি সব সময় সর্বশেষ কাজ ও তার ফলাফল, চলমান কাজ এবং Cancel বোতামগুলো দেখায়।
কম্পাইল একটি ব্যাচ কাজ, যা পেছনে চলে; তাই উইন্ডো ব্যবহার করা যায়। একটি কাজ চলার সময় আবার Compile চাপলে নতুন কাজটি সারিতে যুক্ত হয়।
Code Browser থেকে শুরু করুন: একটি ফোল্ডার বেছে নিন, একটি Python ফাইল নির্বাচন করুন এবং Compile Selected চাপুন। এরপর ফলাফল পরীক্ষা করতে Outputs খুলুন এবং সন্তুষ্ট হলে প্রকাশ করুন। Config-এ আপনার ফোল্ডার নির্ধারণ করুন। যেকোনো Notes শিরোনামে ক্লিক করলে সংশ্লিষ্ট ট্যাব খুলবে।

[tab:code-browser]
একটি ফোল্ডার থেকে সরাসরি Python ফাইল কম্পাইল করুন। Folder বর্তমান ফোল্ডার দেখায়। একটি পাথ লিখুন অথবা ড্রপ-ডাউন তালিকা থেকে সাম্প্রতিক ফোল্ডার বেছে নিন। Browse... ফোল্ডার নির্বাচন করে, Up তার parent ফোল্ডারে যায়, Default Config-এ নির্ধারিত ডিফল্ট ফোল্ডারে ফেরে এবং Refresh ফোল্ডারটি আবার পড়ে। শুধু ওই ফোল্ডারের সরাসরি ভেতরে থাকা ফাইলগুলো দেখানো হয়। আপনি যে ফোল্ডারই খুলুন, সেটি স্বয়ংক্রিয়ভাবে সাম্প্রতিক তালিকায় যুক্ত হয়।
Compile Selected নির্বাচিত ফাইলগুলো কম্পাইল করে। Compile All Shown তালিকার প্রতিটি ফাইল কম্পাইল করে, তাই তালিকা ছোট করতে আগে Search ব্যবহার করুন। One File প্রতিটি প্রোগ্রামকে একটি exe ফাইলে প্যাক করে, Windowed কনসোল উইন্ডো লুকায়, Clean প্রথমে PyInstaller-এর পুরোনো বিল্ড ফাইল সরায় এবং No UPX UPX কম্প্রেশন ধাপ বাদ দেয়; এটি ধীর এবং প্রায়ই শুধু সতর্কবার্তা তৈরি করে। এই চারটি বিকল্প Gateway Apps-এর সঙ্গেও অভিন্ন। শুধু .py এবং .pyw ফাইল কম্পাইল হয়। প্রতিবার চাপলে একটি কাজ তৈরি হয়: অন্য কাজ চললে এটি নিজের পালার জন্য অপেক্ষা করে। Cancel Job চলমান কাজ থামায়, আর Cancel All সারিও খালি করে।
Search-এ লিখলে শুধু সেই ফাইলগুলো দেখায় যাদের নামে ওই লেখা আছে; X বাক্সটি খালি করে। .py / .pyw only বাক্স অন্য ধরনের ফাইল লুকায়। তালিকায় ফাইলের নাম, তৈরির তারিখ, সর্বশেষ পরিবর্তনের তারিখ এবং আকার দেখানো হয়। সর্বশেষ পরিবর্তিত ফাইলটি ওপরে থাকে; সাজানোর ধরন বদলাতে কলামের শিরোনামে ক্লিক করুন।
কোনো Python ফাইলের পাশে ইংরেজি সহায়তা ফাইল থাকলে (name.en.txt, অথবা cpc_ উপসর্গ ছাড়া একই নাম), সেটি exe-এর মধ্যে যুক্ত হয়। তাই কম্পাইল করা প্রোগ্রামের Notes ট্যাবে সব সময় ইংরেজি লেখা থাকে। কম্পাইল লগে "Embedding help" দেখায়।
কোড দেখতে ফাইলে ডান ক্লিক করুন। কোড ও লাইন নম্বরসহ একটি উইন্ডো খুলবে। Copy All পুরো লেখা কপি করে, Open File আপনার নিয়মিত এডিটরে ফাইলটি খোলে এবং Close (অথবা Esc কী) উইন্ডো বন্ধ করে। ফাইল 1 MB-এর বড় হলে শুধু প্রথম এক মেগাবাইট দেখানো হয়; বাইনারি ফাইল দেখানো হয় না। প্রিভিউ ফাইল পরিবর্তন করতে পারে না।
উপরের ডানদিকের CSV ও HTML বোতাম দৃশ্যমান ফাইলগুলো প্রদর্শিত ক্রমে রপ্তানি করে। কোনো ফাইল কখনো ওভাররাইট হয় না; নাম আগে থেকে থাকলে নতুন নামে তারিখ ও সময় যোগ হয়।

[tab:gateway-apps]
আপনার gateway ফাইলে (gateway.json) তালিকাভুক্ত অ্যাপগুলো কম্পাইল করুন। শুধু Python ফাইল (.py এবং .pyw) দেখানো হয়। Reload Gateway ফাইলটি আবার পড়ে এবং Project তালিকাটি একটি প্রকল্প অথবা All-এ সীমাবদ্ধ করে।
এক বা একাধিক অ্যাপ নির্বাচন করে Compile Selected চাপুন। Compile All Shown বর্তমানে তালিকায় থাকা সব অ্যাপ কম্পাইল করে। One File, Windowed, Clean এবং No UPX Code Browser-এর মতোই কাজ করে। প্রতিটি কম্পাইল Config-এ নির্ধারিত Temp Compile আউটপুটের মূল ফোল্ডারের অধীনে নিজস্ব ফোল্ডারে লেখা হয়।
সাজানোর জন্য কলামের শিরোনামে ক্লিক করুন। কোড দেখতে কোনো অ্যাপে ডান ক্লিক করুন। ওপরের ডানদিকের CSV ও HTML বোতাম তালিকাটি ঠিক যেভাবে দেখানো হয়েছে, সেই ক্রমসহ রপ্তানি করে।

[tab:log]
প্রতিটি কাজের রেকর্ড: কখন সারিতে রাখা হয়েছে এবং শুরু হয়েছে, প্রতিটি অ্যাপের PyInstaller আউটপুট (ইন্ডেন্টসহ), প্রতিটি অ্যাপে কত সময় লেগেছে এবং ফলাফল। লাইনে কাজের নম্বর থাকে, যেমন [Job 3 2/5], অর্থাৎ job 3-এর পাঁচটি অ্যাপের মধ্যে দ্বিতীয়টি।
প্রতিটি কাজ Temp Compile আউটপুটের মূল ফোল্ডারের logs ফোল্ডারে আলাদা লগ ফাইল হিসেবেও সংরক্ষিত হয়। কাজ শেষ হলে তার পাথ দেখানো হয়। Clear Log শুধু উইন্ডো খালি করে। উইন্ডো সর্বশেষ 5000 লাইন রাখে।

[tab:outputs]
এই সেশনে Code Browser বা Gateway Apps থেকে যা কম্পাইল করা হয়েছে, টেবিলে তা তালিকাভুক্ত থাকে: অ্যাপ, তার Python সোর্স, তৈরি হওয়া এক্সিকিউটেবল, Result (Queued, Running, Compiled, Failed অথবা Cancelled) এবং কোথায় প্রকাশ করা হয়েছে। কাজ চলার সঙ্গে সঙ্গে সারিগুলো বদলায় এবং আপনার সাজানোর ক্রম বজায় থাকে।
Test Selected PY Python সোর্স চালায় এবং Test Selected EXE Temp Compile থেকে কম্পাইল করা প্রোগ্রাম চালায়। এখানে নির্বাচিত সারিগুলো ব্যবহার করা হয়; কোনো সারি নির্বাচিত না থাকলে সর্বশেষ ব্যবহৃত তালিকায় নির্বাচিত ফাইলগুলো ব্যবহার করা হয়। Open Temp Compile ফাইল ম্যানেজারে বিল্ড ফোল্ডার দেখায় এবং Clear Results টেবিল খালি করে। CSV ও HTML বোতাম টেবিল রপ্তানি করে।
প্রথমে exe পরীক্ষা করুন, তারপর প্রকাশ করুন। দুটি প্রকাশ বোতামই শুধু Compiled দেখানো নির্বাচিত সারিগুলোর ওপর কাজ করে। প্রতিটি বোতাম প্রথমে অ্যাপটিকে Compile Apps-এর নিজস্ব ফোল্ডারে exe এবং settings json-সহ কপি করে। Python ফাইলের পাশের settings json কেবল তখনই কপি হয়, যখন অ্যাপটির সেখানে আগে থেকে সেটি নেই; তাই আপনার পরিবর্তন করা সেটিংস কখনো ওভাররাইট হয় না। অন্য ভাষার সহায়তা ফাইল (name.fr.txt ইত্যাদি) একইভাবে exe-এর পাশে কপি হয়। এগুলো ইচ্ছাকৃতভাবে বাইরের ফাইল, যাতে আবার কম্পাইল না করেই ভাষা যোগ বা সংশোধন করা যায়। ইংরেজি সহায়তা ফাইল কপি হয় না, কারণ এটি exe-এর মধ্যে যুক্ত। এরপর:
Update Gateway gateway.json-এ Python ফাইলের জায়গায় কপি করা exe-এর লিংক বসায়। প্রথমে অনুমতি চায়, gateway.json.bak নামে ব্যাকআপ রাখে এবং অ্যাপটি ফাইলে না থাকলে নতুন এন্ট্রি যোগ করে। Python সোর্সটি source_py নামে এন্ট্রিতে রাখা হয়, তাই অ্যাপটি Gateway Apps-এ থাকে এবং আবার কম্পাইল করা যায়।
Add Start Menu আপনার Start Menu-তে কপি করা exe-এর শর্টকাট যোগ করে। শর্টকাটের নাম অ্যাপের নামে হয় (gateway এন্ট্রির app_name, অথবা Code Browser থেকে আসা ফাইলের নাম) এবং Config-এ নির্ধারিত Start Menu ফোল্ডারে রাখা হয়। শর্টকাট আগে থেকে থাকলে সেটি আপডেট করা হয়।
নতুন বিল্ডের পর একই এন্ট্রি আপডেট করতে এগুলো আবার চালান। কপি ব্যর্থ হলে চলমান অ্যাপ বন্ধ করে আবার চেষ্টা করুন। কম্পাইলের মতো এগুলোও কাজ হিসেবে চলে, তাই চলমান কম্পাইলের পরে সারিতে অপেক্ষা করে। Open Compile Apps, Compile Apps ফোল্ডার খোলে।

[tab:config]
Config প্রোগ্রামের কাজের ধাপ অনুসারে ওপর থেকে নিচে সাজানো। নিচের Save Settings সব সেটিংস settings ফাইলে লেখে এবং কোথায় সংরক্ষিত হয়েছে তা দেখায়।
Code Browser (সাধারণ ফোল্ডার): Default folder হলো Code Browser প্রথমে যে ফোল্ডার খোলে। Browse... সেটি নির্বাচন করে এবং Use Current বর্তমানে Code Browser-এ দেখানো ফোল্ডার ব্যবহার করে। Recent folders ব্যবহৃত ফোল্ডারগুলো নতুন থেকে পুরোনো ক্রমে দেখায় এবং সর্বশেষ 15টি রাখে। Code Browser-এ খোলা প্রতিটি ফোল্ডার স্বয়ংক্রিয়ভাবে যুক্ত হয়। একটি ফোল্ডার লিখুন বা বেছে নিন; তালিকায় যোগ করতে Add, সরাতে Remove অথবা Code Browser-এ দেখাতে Open চাপুন।
Gateway (সোর্স তালিকা): Gateway Apps-এর অ্যাপগুলো তালিকাভুক্ত করা ফাইল। Browse... এটি নির্বাচন করে, Default প্রোগ্রামের ফোল্ডারের gateway.json-এ ফেরে এবং Reload ফাইলটি আবার পড়ে। এখানে কিছু কম্পাইল বা কপি করা হয় না।
Temp Compile: Output root হলো build, dist ও spec ফোল্ডার এবং কাজের লগ রাখার স্থান; প্রতিটি অ্যাপের জন্য আলাদা ফোল্ডার থাকে। এগুলো পরীক্ষার অস্থায়ী ফাইল, সম্পূর্ণ অ্যাপ নয়। Python (PyInstaller) হলো PyInstaller ও Python পরীক্ষা চালানোর জন্য ব্যবহৃত python.exe। এই প্রোগ্রাম নিজেই exe হলে শুধু তখন এটি দরকার, কারণ exe PyInstaller চালাতে পারে না। PATH-এ পাওয়া Python ব্যবহার করতে এটি খালি রাখুন।
Compile Apps: Apps folder হলো সম্পূর্ণ অ্যাপ রাখার স্থান; প্রতিটি অ্যাপের নিজস্ব ফোল্ডারে exe এবং settings json থাকে। Start Menu শর্টকাট ও নতুন gateway এন্ট্রি এই কপির দিকে নির্দেশ করে। Start Menu folder হলো শর্টকাট যোগ করার ফোল্ডারের নাম। Browse... দিয়ে নতুন Apps ফোল্ডার বেছে নিলে settings ফাইলটিও সেখানে রাখতে চান কি না জিজ্ঞাসা করা হবে।
এই প্রোগ্রাম নিজেই exe হলে ইংরেজি সহায়তা এর মধ্যে যুক্ত থাকে। প্রথমবার চালু হলে সম্পাদনার জন্য exe-এর পাশে একটি কপি রাখা হয়; এটি কখনো প্রতিস্থাপিত হয় না এবং মুছে ফেললে ভেতরে থাকা লেখা আবার দেখা যায়। অন্য ভাষার সহায়তা exe-এর পাশে সাধারণ ফাইল হিসেবে থাকে।
Settings file: এই প্রোগ্রামের নিজস্ব সেটিংস (python_compiler.json) কোথায় রাখা হয় তা দেখায়। শুরুতে এগুলো প্রোগ্রামের একই ফোল্ডারে থাকে (exe অথবা এই script), কখনো অস্থায়ী ফোল্ডারে নয়। Browse... অন্য ফোল্ডার বেছে নেয়, Use Apps Folder সেটিংস Compile Apps ফোল্ডারে সরায় এবং Default সেগুলো প্রোগ্রামের ফোল্ডারে ফিরিয়ে আনে। বর্তমান সেটিংস নতুন স্থানে সংরক্ষিত হয় এবং প্রোগ্রামের ফোল্ডারে একটি ছোট নোট থাকে, যেখানে অবস্থান লেখা থাকে, যাতে পরেরবার চালু হলে প্রোগ্রাম সেটিংস খুঁজে পায়। পুরোনো কপি আগের জায়গায় থাকে। শুরুতে settings ফোল্ডার পাওয়া না গেলে (যেমন নেটওয়ার্ক ড্রাইভ), ডিফল্ট সেটিংস ব্যবহার করা হয় এবং নোটটি রাখা হয়।
রং, ঘনত্ব এবং উইন্ডোর আকার UI Choices-এ রয়েছে।

[tab:ui-choices]
রঙের থিম, ঘনত্ব এবং উইন্ডোর আকার বেছে নিন। Use Current Size বর্তমান উইন্ডোর আকার নেয় এবং Apply + Save আপনার পছন্দ প্রয়োগ ও সংরক্ষণ করে। তালিকার ডোরা আপনার নির্বাচিত থিম অনুসরণ করে। এই সেটিংস অ্যাপের চেহারা নিয়ন্ত্রণ করে। ফোল্ডার ও বিকল্পগুলো Config-এ থাকে।

[tab:gateway]
নিবন্ধিত অ্যাপ্লিকেশন, ফাইল, ফোল্ডার এবং লিংক খুলতে শেয়ার করা launcher ব্যবহার করুন। এটি প্রোগ্রামের ফোল্ডারের gateway_cards.json ফাইলে কার্ডগুলো রাখে। Gateway, Gateway Apps তালিকা সরবরাহকারী gateway ফাইল থেকে আলাদা।
