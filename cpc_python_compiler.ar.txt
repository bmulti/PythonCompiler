[intro]
يحوّل Python Compiler برامج Python إلى برامج Windows باستخدام PyInstaller، ويختبرها وينشرها. ويتبع المسار التالي:
Code Browser أو Gateway Apps (المصدر البرمجي بلغة Python) > Temp Compile (ملفات البناء والاختبار) > Outputs (الاختبار ثم النشر) > Compile Apps (التطبيقات المكتملة وقائمة Start Menu وإدخال Gateway الجديد).
يقوم Code Browser بتجميع ملفات Python من أي مجلد. ويقوم Gateway Apps بتجميع التطبيقات المدرجة في ملف gateway (gateway.json). تتيح كلتا القائمتين قراءة الشيفرة بالنقر بزر الفأرة الأيمن. يختبر Outputs ما تم إنشاؤه وينشره. ويسجل Log كل ما يحدث. يعرض السطر أسفل النافذة دائمًا آخر إجراء ونتيجته والمهمة قيد التشغيل وأزرار Cancel.
التجميع مهمة دفعية تعمل في الخلفية، ولذلك تظل النافذة قابلة للاستخدام. اضغط Compile مرة أخرى أثناء تشغيل مهمة، وستُضاف المهمة الجديدة إلى قائمة الانتظار.
ابدأ من Code Browser: اختر مجلدًا، وحدد ملف Python، ثم اضغط Compile Selected. بعد ذلك افتح Outputs لتجربة النتيجة، وانشرها عندما تكون راضيًا عنها. حدّد مجلداتك في Config. انقر أي عنوان Notes لفتح علامة التبويب المقابلة.

[tab:code-browser]
جمّع ملفات Python مباشرة من مجلد. يعرض Folder المجلد الحالي. اكتب مسارًا أو اختر أحد المجلدات الأخيرة من القائمة المنسدلة. يختار Browse... مجلدًا، وينتقل Up إلى المجلد الأب، ويعود Default إلى المجلد الافتراضي المحدد في Config، ويعيد Refresh قراءة المجلد. لا تُعرض إلا الملفات الموجودة مباشرة داخل المجلد. يُضاف كل مجلد تفتحه تلقائيًا إلى قائمة المجلدات الأخيرة.
يجمع Compile Selected الملفات المحددة. ويجمع Compile All Shown كل ملف في القائمة، لذا استخدم Search أولًا لتضييق القائمة. يضع One File كل برنامج في ملف exe واحد، ويخفي Windowed نافذة وحدة التحكم، ويحذف Clean ملفات البناء القديمة الخاصة بـ PyInstaller أولًا، ويتجاوز No UPX خطوة ضغط UPX، وهي بطيئة وغالبًا لا تنتج سوى تحذيرات. هذه الخيارات الأربعة مشتركة أيضًا مع Gateway Apps. لا تُجمع إلا ملفات .py و.pyw. ينشئ كل ضغط مهمة واحدة؛ وإذا كانت هناك مهمة أخرى قيد التشغيل، تنتظر هذه المهمة دورها. يوقف Cancel Job المهمة الجارية، كما يمسح Cancel All قائمة الانتظار.
اكتب في Search لعرض الملفات التي تحتوي أسماؤها على النص المدخل فقط؛ ويمسح X مربع البحث. يخفي مربع .py / .pyw only أنواع الملفات الأخرى. تعرض القائمة اسم الملف وتاريخ إنشائه وآخر تعديل عليه وحجمه. يظهر الملف الأحدث تعديلًا في الأعلى؛ انقر عنوان عمود لتغيير الترتيب.
إذا وُجد ملف مساعدة باللغة الإنجليزية بجوار ملف Python (name.en.txt، أو الاسم من دون البادئة cpc_)، فسيُضمّن داخل exe، ولذلك تحتوي علامة Notes في البرنامج المجمّع دائمًا على النص الإنجليزي. يعرض سجل التجميع "Embedding help".
انقر بزر الفأرة الأيمن على ملف لعرض الشيفرة. تفتح نافذة تعرض الشيفرة وأرقام الأسطر. ينسخ Copy All النص كاملًا، ويفتح Open File الملف في المحرر المعتاد، ويغلق Close (أو مفتاح Esc) النافذة. إذا تجاوز حجم الملف 1 MB، فلن يظهر إلا الميغابايت الأول؛ ولا تُعرض الملفات الثنائية. لا يمكن للمعاينة تغيير الملف.
تصدّر أزرار CSV وHTML في أعلى اليمين الملفات المعروضة بالترتيب الظاهر. لا يُستبدل أي ملف؛ وإذا كان الاسم مستخدمًا، يُضاف التاريخ والوقت إلى الاسم الجديد.

[tab:gateway-apps]
جمّع التطبيقات المدرجة في ملف gateway (gateway.json). لا تظهر إلا ملفات Python (.py و.pyw). يعيد Reload Gateway قراءة الملف، ويقصر Project القائمة على مشروع واحد أو على All.
حدد تطبيقًا واحدًا أو أكثر، ثم اضغط Compile Selected. يجمع Compile All Shown كل التطبيقات الموجودة حاليًا في القائمة. تعمل خيارات One File وWindowed وClean وNo UPX كما في Code Browser. يُكتب كل تجميع في مجلد مستقل ضمن جذر إخراج Temp Compile المحدد في Config.
انقر عنوان عمود للفرز. انقر بزر الفأرة الأيمن على تطبيق لعرض شيفرته. تصدّر أزرار CSV وHTML في أعلى اليمين القائمة كما تظهر تمامًا، بما في ذلك ترتيب الفرز.

[tab:log]
سجل لكل مهمة: وقت إضافتها إلى قائمة الانتظار ووقت بدء تشغيلها، ومخرجات PyInstaller لكل تطبيق (مع المسافة البادئة)، والوقت الذي استغرقه كل تطبيق، والنتيجة. تُعلّم الأسطر برقم المهمة، مثل [Job 3 2/5]، أي التطبيق الثاني من أصل خمسة في المهمة 3.
يُحفظ كل عمل أيضًا في ملف سجل مستقل داخل مجلد logs ضمن جذر إخراج Temp Compile، ويظهر مساره عند انتهاء المهمة. يمسح Clear Log النافذة فقط. تحتفظ النافذة بآخر 5000 سطر.

[tab:outputs]
يسرد الجدول ما جمعته خلال هذه الجلسة من Code Browser أو Gateway Apps: التطبيق، ومصدر Python الخاص به، والملف التنفيذي الناتج، والنتيجة (Queued أو Running أو Compiled أو Failed أو Cancelled)، ومكان نشره. تتغير الصفوف أثناء تشغيل المهمة، ويظل ترتيب الفرز الذي اخترته محفوظًا.
يشغّل Test Selected PY مصدر Python، ويشغّل Test Selected EXE البرنامج المجمّع من Temp Compile. يستخدمان الصفوف المحددة هنا؛ وإذا لم يكن أي صف محددًا، فيستخدمان الملفات المحددة في آخر قائمة استخدمتها. يعرض Open Temp Compile مجلد البناء في مدير الملفات، ويفرغ Clear Results الجدول. وتصدر أزرار CSV وHTML محتوياته.
اختبر exe أولًا، ثم انشره. يعمل زرا النشر على الصفوف المحددة التي تظهر عليها الحالة Compiled. ينسخ كل زر التطبيق أولًا إلى مجلده الخاص في Compile Apps، مع exe وملف إعدادات json. لا يُنسخ ملف إعدادات json من جوار ملف Python إلا إذا لم يكن للتطبيق ملف هناك بالفعل، ولذلك لا تُستبدل الإعدادات التي سبق أن غيّرتها أبدًا. وتُنسخ ملفات المساعدة باللغات الأخرى (مثل name.fr.txt) إلى جوار exe بالطريقة نفسها. تُترك هذه الملفات خارجية عمدًا، بحيث يمكن إضافة لغة أو تصحيحها دون إعادة التجميع. لا يُنسخ ملف المساعدة الإنجليزي لأنه مضمّن داخل exe. ثم:
يستبدل Update Gateway ملف Python في gateway.json برابط إلى exe المنسوخ. يطلب التأكيد أولًا، ويحتفظ بنسخة احتياطية باسم gateway.json.bak، ويضيف إدخالًا إذا لم يكن التطبيق موجودًا في الملف. يُحتفظ بمصدر Python في الإدخال باسم source_py، لذلك يبقى التطبيق ضمن Gateway Apps ويمكن تجميعه مرة أخرى.
يضيف Add Start Menu اختصارًا إلى exe المنسوخ في قائمة Start Menu. يُسمّى الاختصار باسم التطبيق (app_name في إدخال gateway، أو اسم الملف إذا كان من Code Browser)، ويوضع في مجلد Start Menu المحدد في Config. إذا كان الاختصار موجودًا بالفعل، فسيتم تحديثه.
شغّل هذه الأوامر مرة أخرى بعد إنشاء إصدار جديد لتحديث الإدخالات نفسها. إذا فشل النسخ، فأغلق التطبيق قيد التشغيل وحاول مرة أخرى. تعمل هذه الأوامر كمهام مثل التجميع، ولذلك تنتظر خلف أي عملية تجميع قيد التشغيل. يفتح Open Compile Apps مجلد Compile Apps.

[tab:config]
يتبع Config مسار البرنامج من الأعلى إلى الأسفل. يحفظ Save Settings في الأسفل جميع الإعدادات في ملف الإعدادات ويعرض مكان حفظها.
Code Browser (المجلدات العادية): المجلد Default folder هو المجلد الذي يفتحه Code Browser أولًا. يختاره Browse...، ويستخدم Use Current المجلد الذي يعرضه Code Browser حاليًا. تسرد Recent folders المجلدات التي استخدمتها، من الأحدث إلى الأقدم، وتحتفظ بآخر 15 مجلدًا. يُضاف تلقائيًا كل مجلد تفتحه في Code Browser. اكتب مجلدًا أو اختره، ثم اضغط Add لإضافته إلى القائمة، أو Remove لإزالته، أو Open لعرضه في Code Browser.
Gateway (قائمة المصدر): الملف الذي يسرد التطبيقات في Gateway Apps. يختاره Browse...، ويعيد Default إلى gateway.json الموجود في مجلد البرنامج، ويعيد Reload قراءته. لا يتم هنا تجميع أي شيء أو نسخه.
Temp Compile: يمثل Output root المكان الذي توجد فيه مجلدات build وdist وspec وسجلات المهام، مع مجلد مستقل لكل تطبيق. هذه ملفات مؤقتة للاختبار وليست التطبيق النهائي. Python (PyInstaller) هو ملف python.exe المستخدم لتشغيل PyInstaller واختبارات Python. لا يلزم إلا عندما يكون هذا البرنامج نفسه ملف exe، لأن exe لا يستطيع تشغيل PyInstaller. اتركه فارغًا لاستخدام Python الموجود في PATH.
Compile Apps: مجلد Apps folder هو المكان الذي تُحفظ فيه التطبيقات المكتملة، ولكل تطبيق مجلده الخاص الذي يحتوي على exe وملف إعدادات json. يشير اختصار Start Menu وإدخال gateway الجديد إلى هذه النسخة. Start Menu folder هو اسم المجلد الذي تُضاف إليه الاختصارات. عند اختيار مجلد Apps جديد باستخدام Browse...، سيُسألك ما إذا كنت تريد الاحتفاظ بملف الإعدادات فيه أيضًا.
عندما يكون هذا البرنامج نفسه ملف exe، تكون المساعدة الإنجليزية مضمّنة فيه. عند التشغيل الأول، توضع نسخة بجوار exe لتعديلها؛ ولا تُستبدل أبدًا، ويؤدي حذفها إلى ظهور النص المضمّن من جديد. أما المساعدة باللغات الأخرى فهي ملف عادي بجوار exe.
Settings file: يعرض مكان حفظ إعدادات هذا البرنامج نفسه (python_compiler.json). تكون في البداية في المجلد نفسه الذي يوجد فيه البرنامج (exe أو هذا البرنامج النصي)، وليس في مجلد مؤقت أبدًا. يختار Browse... مجلدًا آخر، وينقل Use Apps Folder الملف إلى مجلد Compile Apps، ويعيد Default الملف إلى مجلد البرنامج. تُحفظ الإعدادات الحالية في الموقع الجديد، ويحتفظ مجلد البرنامج بملاحظة قصيرة توضّح مكانها حتى يعثر عليها البرنامج عند التشغيل التالي. تبقى النسخة القديمة في مكانها. إذا لم يكن مجلد الإعدادات متاحًا عند بدء التشغيل (مثلًا بسبب محرك أقراص شبكي)، فستُستخدم الإعدادات الافتراضية وتبقى الملاحظة محفوظة.
توجد الألوان والكثافة وحجم النافذة في UI Choices.

[tab:ui-choices]
اختر سمة الألوان والكثافة وحجم النافذة. يستخدم Use Current Size حجم النافذة الحالي، ويطبّق Apply + Save اختياراتك ويحفظها. تتبع خطوط الصفوف في القائمة السمة التي تختارها. تتحكم هذه الإعدادات في مظهر التطبيق. أما المجلدات والخيارات فتوجد في Config.

[tab:gateway]
استخدم المشغّل المشترك لفتح التطبيقات والملفات والمجلدات والروابط المسجلة. يحتفظ ببطاقاته في gateway_cards.json داخل مجلد البرنامج. Gateway منفصل عن ملف gateway الذي يوفّر قائمة Gateway Apps.
