[intro]
Python Compiler, PyInstaller का उपयोग करके Python प्रोग्राम को Windows प्रोग्राम में बदलता है, उनका परीक्षण करता है और उन्हें प्रकाशित करता है। इसकी प्रक्रिया इस प्रकार है:
Code Browser या Gateway Apps (Python स्रोत कोड) > Temp Compile (बिल्ड और परीक्षण फ़ाइलें) > Outputs (पहले परीक्षण, फिर प्रकाशित करना) > Compile Apps (तैयार ऐप, Start Menu और नई Gateway प्रविष्टि)।
Code Browser किसी भी फ़ोल्डर से Python फ़ाइलों को कंपाइल करता है। Gateway Apps आपकी gateway फ़ाइल (gateway.json) में सूचीबद्ध ऐप को कंपाइल करता है। दोनों सूचियों में राइट-क्लिक करके कोड देखा जा सकता है। Outputs बनी हुई चीज़ का परीक्षण करता है और उसे प्रकाशित करता है। Log हर गतिविधि दर्ज करता है। विंडो के नीचे की पंक्ति हमेशा पिछली कार्रवाई और उसका परिणाम, चल रहे कार्य तथा Cancel बटन दिखाती है।
कंपाइल करना एक बैच कार्य है जो पृष्ठभूमि में चलता है, इसलिए विंडो उपयोग करने योग्य रहती है। कोई कार्य चलते समय फिर से Compile दबाएँ, तो नया कार्य कतार में जुड़ जाता है।
Code Browser से शुरू करें: फ़ोल्डर चुनें, Python फ़ाइल चुनें और Compile Selected दबाएँ। फिर परिणाम आज़माने के लिए Outputs खोलें और संतुष्ट होने पर उसे प्रकाशित करें। Config में अपने फ़ोल्डर निर्धारित करें। Notes के किसी भी शीर्षक पर क्लिक करने से उसका संबंधित टैब खुलता है।

[tab:code-browser]
किसी फ़ोल्डर से सीधे Python फ़ाइलें कंपाइल करें। Folder वर्तमान फ़ोल्डर दिखाता है। कोई पथ लिखें या ड्रॉप-डाउन सूची से हाल के फ़ोल्डरों में से चुनें। Browse... फ़ोल्डर चुनता है, Up उसके मूल फ़ोल्डर में जाता है, Default Config में निर्धारित डिफ़ॉल्ट फ़ोल्डर पर लौटता है और Refresh फ़ोल्डर को फिर से पढ़ता है। केवल उसी फ़ोल्डर में सीधे मौजूद फ़ाइलें दिखाई जाती हैं। आपके द्वारा खोला गया हर फ़ोल्डर अपने आप हाल की सूची में जुड़ जाता है।
Compile Selected चुनी हुई फ़ाइलों को कंपाइल करता है। Compile All Shown सूची की हर फ़ाइल को कंपाइल करता है, इसलिए सूची सीमित करने के लिए पहले Search का उपयोग करें। One File प्रत्येक प्रोग्राम को एक exe में पैक करता है, Windowed कंसोल विंडो छिपाता है, Clean पहले PyInstaller की पुरानी बिल्ड फ़ाइलें हटाता है और No UPX UPX संपीड़न चरण छोड़ देता है, जो धीमा है और अक्सर केवल चेतावनियाँ देता है। ये चारों विकल्प Gateway Apps के साथ भी साझा हैं। केवल .py और .pyw फ़ाइलें कंपाइल होती हैं। हर बार दबाने पर एक कार्य बनता है: यदि दूसरा कार्य चल रहा है, तो यह अपनी बारी की प्रतीक्षा करता है। Cancel Job चल रहे कार्य को रोकता है और Cancel All कतार भी खाली करता है।
Search में लिखें ताकि केवल उन फ़ाइलों के नाम दिखें जिनमें वह पाठ है; X बॉक्स खाली करता है। .py / .pyw only बॉक्स अन्य प्रकार की फ़ाइलें छिपाता है। सूची में फ़ाइल का नाम, बनने की तारीख, आखिरी बार बदले जाने की तारीख और आकार दिखता है। सबसे हाल में बदली गई फ़ाइल सबसे ऊपर होती है; क्रम बदलने के लिए किसी कॉलम शीर्षक पर क्लिक करें।
यदि किसी Python फ़ाइल के साथ अंग्रेज़ी सहायता फ़ाइल मौजूद है (name.en.txt, या cpc_ उपसर्ग के बिना वही नाम), तो उसे exe में शामिल किया जाता है। इसलिए कंपाइल किए गए प्रोग्राम के Notes टैब में अंग्रेज़ी पाठ हमेशा उपलब्ध रहता है। कंपाइल लॉग में "Embedding help" दिखता है।
कोड देखने के लिए फ़ाइल पर राइट-क्लिक करें। कोड और पंक्ति संख्याओं वाली विंडो खुलती है। Copy All पूरा पाठ कॉपी करता है, Open File फ़ाइल को आपके सामान्य संपादक में खोलता है और Close (या Esc कुंजी) विंडो बंद करता है। 1 MB से बड़ी फ़ाइल का केवल पहला मेगाबाइट दिखाया जाता है और बाइनरी फ़ाइलें नहीं दिखाई जातीं। पूर्वावलोकन फ़ाइल को बदल नहीं सकता।
ऊपर दाईं ओर के CSV और HTML बटन दिखाई गई फ़ाइलों को उसी क्रम में निर्यात करते हैं। किसी फ़ाइल को कभी ओवरराइट नहीं किया जाता; यदि नाम पहले से मौजूद है, तो नए नाम में तारीख और समय जोड़ दिए जाते हैं।

[tab:gateway-apps]
अपनी gateway फ़ाइल (gateway.json) में सूचीबद्ध ऐप कंपाइल करें। केवल Python फ़ाइलें (.py और .pyw) दिखाई जाती हैं। Reload Gateway फ़ाइल को फिर से पढ़ता है और Project सूची को एक प्रोजेक्ट या All तक सीमित करता है।
एक या अधिक ऐप चुनें, फिर Compile Selected दबाएँ। Compile All Shown सूची में वर्तमान में दिखाई देने वाले सभी ऐप कंपाइल करता है। One File, Windowed, Clean और No UPX, Code Browser की तरह काम करते हैं। हर कंपाइल को Config में निर्धारित Temp Compile आउटपुट रूट के अंतर्गत अपने अलग फ़ोल्डर में रखा जाता है।
क्रम बदलने के लिए कॉलम शीर्षक पर क्लिक करें। कोड देखने के लिए किसी ऐप पर राइट-क्लिक करें। ऊपर दाईं ओर के CSV और HTML बटन सूची को ठीक उसी तरह निर्यात करते हैं जैसे वह दिखाई देती है, जिसमें क्रम भी शामिल है।

[tab:log]
हर कार्य का रिकॉर्ड: उसे कतार में कब रखा गया और कब शुरू हुआ, हर ऐप का PyInstaller आउटपुट (इंडेंट सहित), हर ऐप में लगा समय और परिणाम। पंक्तियों पर कार्य संख्या अंकित होती है, जैसे [Job 3 2/5], जिसका अर्थ है कार्य 3 में पाँच ऐप में से दूसरा ऐप।
हर कार्य Temp Compile आउटपुट रूट के अंतर्गत logs फ़ोल्डर में अपनी अलग लॉग फ़ाइल के रूप में भी सहेजा जाता है। कार्य समाप्त होने पर उसका पथ दिखाया जाता है। Clear Log केवल विंडो खाली करता है। विंडो नवीनतम 5000 पंक्तियाँ रखती है।

[tab:outputs]
तालिका इस सत्र में Code Browser या Gateway Apps से कंपाइल की गई चीज़ें दिखाती है: ऐप, उसका Python स्रोत, बनी हुई निष्पादन फ़ाइल, Result (Queued, Running, Compiled, Failed या Cancelled), और उसे कहाँ प्रकाशित किया गया। कार्य चलते समय पंक्तियाँ बदलती हैं और चुना गया क्रम बना रहता है।
Test Selected PY Python स्रोत चलाता है और Test Selected EXE Temp Compile से कंपाइल किया गया प्रोग्राम चलाता है। ये यहाँ चुनी गई पंक्तियों का उपयोग करते हैं; यदि कोई पंक्ति नहीं चुनी गई है, तो पिछली बार उपयोग की गई सूची में चुनी गई फ़ाइलें इस्तेमाल होती हैं। Open Temp Compile फ़ाइल प्रबंधक में बिल्ड फ़ोल्डर दिखाता है और Clear Results तालिका खाली करता है। CSV और HTML बटन इसे निर्यात करते हैं।
पहले exe का परीक्षण करें, फिर उसे प्रकाशित करें। दोनों प्रकाशन बटन केवल उन चुनी हुई पंक्तियों पर काम करते हैं जिनका परिणाम Compiled है। हर बटन पहले ऐप को Compile Apps में उसके अपने फ़ोल्डर में exe और settings json के साथ कॉपी करता है। Python फ़ाइल के पास से settings json तभी कॉपी किया जाता है जब ऐप के पास वहाँ पहले से ऐसा फ़ाइल न हो; इसलिए आपके बदले हुए सेटिंग कभी ओवरराइट नहीं होते। अन्य भाषाओं की सहायता फ़ाइलें (name.fr.txt आदि) भी इसी तरह exe के पास कॉपी की जाती हैं। इन्हें जानबूझकर बाहरी रखा गया है ताकि दोबारा कंपाइल किए बिना भाषा जोड़ी या सुधारी जा सके। अंग्रेज़ी सहायता फ़ाइल कॉपी नहीं होती क्योंकि वह exe में शामिल है। इसके बाद:
Update Gateway, gateway.json में Python फ़ाइल को कॉपी किए गए exe के लिंक से बदलता है। पहले पुष्टि माँगी जाती है, gateway.json.bak नाम का बैकअप रखा जाता है और यदि ऐप फ़ाइल में नहीं था तो नई प्रविष्टि जोड़ी जाती है। Python स्रोत को source_py के रूप में प्रविष्टि में रखा जाता है, इसलिए ऐप Gateway Apps में बना रहता है और फिर से कंपाइल किया जा सकता है।
Add Start Menu, Start Menu में कॉपी किए गए exe का शॉर्टकट जोड़ता है। शॉर्टकट का नाम ऐप के नाम पर होता है (gateway प्रविष्टि में app_name, या Code Browser से आई फ़ाइल का नाम) और इसे Config में निर्धारित Start Menu फ़ोल्डर में रखा जाता है। यदि शॉर्टकट पहले से मौजूद है, तो उसे अपडेट किया जाता है।
नई बिल्ड के बाद इन्हें फिर चलाएँ ताकि वही प्रविष्टियाँ अपडेट हो जाएँ। कॉपी विफल होने पर चल रहे ऐप को बंद करके फिर प्रयास करें। ये कंपाइल की तरह कार्य के रूप में चलते हैं, इसलिए चल रहे कंपाइल के पीछे कतार में लगते हैं। Open Compile Apps, Compile Apps फ़ोल्डर खोलता है।

[tab:config]
Config प्रोग्राम के प्रवाह का ऊपर से नीचे तक अनुसरण करता है। नीचे मौजूद Save Settings सभी सेटिंग को settings फ़ाइल में लिखता है और बताता है कि वे कहाँ सहेजी गईं।
Code Browser (सामान्य फ़ोल्डर): Default folder वह फ़ोल्डर है जिसे Code Browser सबसे पहले खोलता है। Browse... उसे चुनता है और Use Current वह फ़ोल्डर उपयोग करता है जो Code Browser अभी दिखा रहा है। Recent folders आपके उपयोग किए गए फ़ोल्डरों को नवीनतम पहले क्रम में दिखाता है और अंतिम 15 रखता है। Code Browser में खोला गया हर फ़ोल्डर अपने आप जुड़ जाता है। कोई फ़ोल्डर लिखें या चुनें और सूची में जोड़ने के लिए Add, हटाने के लिए Remove या Code Browser में दिखाने के लिए Open दबाएँ।
Gateway (स्रोत सूची): वह फ़ाइल जो Gateway Apps के ऐप सूचीबद्ध करती है। Browse... उसे चुनता है, Default प्रोग्राम के फ़ोल्डर में gateway.json पर लौटता है और Reload उसे फिर से पढ़ता है। यहाँ कुछ भी कंपाइल या कॉपी नहीं होता।
Temp Compile: Output root वह स्थान है जहाँ build, dist और spec फ़ोल्डर तथा कार्य लॉग रखे जाते हैं; हर ऐप का अपना फ़ोल्डर होता है। ये परीक्षण के लिए अस्थायी फ़ाइलें हैं, तैयार ऐप नहीं। Python (PyInstaller) वह python.exe है जिसका उपयोग PyInstaller और Python परीक्षण चलाने के लिए होता है। इसकी आवश्यकता केवल तब होती है जब यह प्रोग्राम स्वयं exe हो, क्योंकि exe PyInstaller नहीं चला सकता। PATH में मिला Python उपयोग करने के लिए इसे खाली छोड़ें।
Compile Apps: Apps folder वह स्थान है जहाँ तैयार ऐप रखे जाते हैं; हर ऐप अपने फ़ोल्डर में exe और settings json के साथ रहता है। Start Menu शॉर्टकट और नई gateway प्रविष्टि इसी कॉपी की ओर संकेत करते हैं। Start Menu folder उस फ़ोल्डर का नाम है जहाँ शॉर्टकट जोड़े जाते हैं। Browse... से नया Apps फ़ोल्डर चुनने पर पूछा जाता है कि settings फ़ाइल भी वहाँ रखनी है या नहीं।
जब यह प्रोग्राम स्वयं exe होता है, तो इसकी अंग्रेज़ी सहायता उसमें शामिल होती है। पहली बार शुरू होने पर संपादन के लिए exe के पास उसकी एक प्रति रखी जाती है; इसे कभी बदला नहीं जाता और इसे हटाने पर शामिल मूल पाठ फिर दिखाई देता है। अन्य भाषाओं की सहायता exe के पास सामान्य फ़ाइल के रूप में रहती है।
Settings file: यह दिखाती है कि इस प्रोग्राम की अपनी सेटिंग (python_compiler.json) कहाँ रखी जाती हैं। शुरुआत में वे प्रोग्राम के उसी फ़ोल्डर में होती हैं जहाँ exe या यह script है; वे कभी अस्थायी फ़ोल्डर में नहीं रखी जातीं। Browse... दूसरा फ़ोल्डर चुनता है, Use Apps Folder सेटिंग्स Compile Apps फ़ोल्डर में ले जाता है और Default उन्हें प्रोग्राम फ़ोल्डर में वापस लाता है। वर्तमान सेटिंग नई जगह सहेजी जाती हैं और प्रोग्राम फ़ोल्डर में एक छोटा नोट रहता है जो उनका स्थान बताता है, ताकि अगली बार शुरू होने पर प्रोग्राम उन्हें ढूँढ़ सके। पुरानी प्रति वहीं रहती है। यदि शुरू होते समय settings फ़ोल्डर उपलब्ध न हो (उदाहरण के लिए नेटवर्क ड्राइव), तो डिफ़ॉल्ट सेटिंग उपयोग होती हैं और नोट बना रहता है।
